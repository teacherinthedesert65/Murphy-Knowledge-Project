How Large Language Models Work

Modern language models can write, summarize, translate, reason through problems, and use tools—but their core operation is still grounded in predicting and processing sequences of tokens.

Murphy Knowledge Project • Reviewed September 2026

A large language model is a neural network trained on enormous collections of text and other data so that it can estimate which tokens are likely to follow a given context. Scale, transformer architecture, training methods, and tool use can make that simple-sounding objective produce surprisingly general capabilities.

From words to tokens

Models do not usually read text as whole words. A tokenizer breaks text into smaller units called tokens. A token may be a word, part of a word, punctuation, or another encoded unit. The model converts those tokens into numerical representations and processes relationships among them.

The transformer changed the field

The 2017 paper Attention Is All You Need introduced the transformer architecture. Its attention mechanisms let a model weigh relationships among different positions in a sequence, helping it use context efficiently and making large-scale parallel training practical. Modern systems have evolved substantially, but transformer-style architectures remain foundational to many language models.

TrainingThe model adjusts billions of numerical parameters to reduce prediction error across large datasets.
InferenceAfter training, the model uses those learned parameters and the current prompt to generate or score new tokens.
ContextThe information available in the active context window strongly shapes what the model can use during a response.

Why fluent answers can still be wrong

Language models learn statistical structure, not a guaranteed database of verified facts. A model can generate an answer that is linguistically convincing while containing an incorrect detail, unsupported citation, faulty assumption, or outdated claim. Retrieval systems, external tools, evaluation, and human verification can improve reliability, but they do not eliminate the need to check consequential information.

Reasoning, tools, and agents

Newer systems can spend additional computation on difficult problems, call external tools, search information, write and execute code, or carry out multi-step workflows. Those capabilities extend what a base language model can accomplish, but they also create new questions about permissions, monitoring, evaluation, and error recovery.

The useful mental model is neither “just autocomplete” nor “a human mind in a computer.” A modern language model is a learned computational system whose next-token machinery can support complex behavior when combined with scale, context, reasoning strategies, tools, and feedback.

Reliability is an engineering problem

NIST’s Generative AI Profile emphasizes that organizations should manage risks across the full AI lifecycle rather than assuming that model capability automatically implies trustworthiness. Testing, documentation, monitoring, human oversight, and clear boundaries around high-impact uses all matter.
